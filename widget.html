        WHY ADD FASQOO?

        WIDGET FAQ
        
Frequently asked questions

      


      

        Does the widget work on mobile devices?
        
Yes. The widget is designed for responsive layouts and can be embedded on desktop and mobile websites.

      

      

        Can I change the widget colors?
        
Yes. Use the builder to customize the available visual settings and then generate a new embed code.

      

      

        Do I need to build the speed test myself?
        
No. The builder generates the widget code for you. You only need to add the generated code to a supported embed or HTML area.

      

      

        Is the speed test a real measurement?
        
The Fasqoo widget is intended to perform browser-based network measurements. Actual results can vary depending on the visitor's device, browser, network, Wi-Fi conditions and route to the measurement service.

      

      

        Can I use the widget on more than one website?
        
The generated embed code can be placed on websites where you are permitted to add custom HTML or embed code. Always check the rules of the platform you use.
