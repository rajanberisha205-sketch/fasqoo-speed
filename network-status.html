Measurement accuracy and limitations

Browser measurements describe the path between the visitor's browser and Fasqoo. They do not automatically prove that an ISP, router, DNS resolver or geographic region is responsible for a problem. True ICMP packet loss, traceroute, resolver comparison, server-side TCP diagnostics and global monitoring require Fasqoo backend probes.
