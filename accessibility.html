Accessibility Statement – Fasqoo

Last updated: September 3, 2026

Fasqoo is committed to making its website accessible and easy to use for as many people as possible, regardless of their device, abilities, or the technology they use to access the internet.

Our Commitment

We continuously work to improve the accessibility, usability, and overall experience of the Fasqoo website. Our goal is to provide a website that can be used by people with different needs, including users who rely on assistive technologies such as screen readers, keyboard navigation, or browser accessibility features.

Accessibility Features

Fasqoo aims to provide:

  • Clear and readable text
  • Sufficient contrast between text and backgrounds
  • Keyboard-friendly navigation
  • Clearly identifiable buttons and links
  • Descriptive labels for important controls
  • Responsive layouts for desktop, tablet, and mobile devices
  • Support for modern browsers and accessibility technologies
  • Accessible navigation and website structure

Speed Test Accessibility

The Fasqoo Internet Speed Test is designed to be easy to operate. Important controls, including starting and stopping a test, are presented as interactive buttons.

Test results such as download speed, upload speed, ping, and jitter are displayed in a clear format. We are continuously working to improve the accessibility of the speed-test interface and its results.

Keyboard Navigation

Where possible, Fasqoo supports navigation using a keyboard without requiring a mouse. Users can use standard keyboard controls such as:

  • Tab to move between interactive elements
  • Shift + Tab to move backwards
  • Enter or Space to activate buttons and links

Screen Readers

We aim to structure the website so that important information and interactive elements can be understood by commonly used screen-reader software.

We continue to improve labels, headings, navigation elements, and status information to provide a better experience for screen-reader users.

Mobile Accessibility

Fasqoo is designed to work across different screen sizes, including smartphones and tablets. The website automatically adapts its layout to provide a usable experience on smaller screens.

Browser and Assistive Technology Support

Fasqoo aims to support current versions of commonly used browsers and accessibility technologies. Because browsers, operating systems, and assistive technologies can behave differently, some parts of the website may not work identically in every environment.

Continuous Improvement

Accessibility is an ongoing process. We regularly review the Fasqoo website and make improvements where possible. As new accessibility technologies and standards develop, we will continue working to improve the experience for all users.

Feedback

If you experience an accessibility problem while using Fasqoo, we would appreciate your feedback. Please contact us and describe:

  • The page where the problem occurred
  • What you were trying to do
  • What went wrong
  • Which device and browser you were using, if known

Your feedback helps us identify problems and improve the website.
