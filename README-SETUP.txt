FASQOO GEMINI DIRECT AI SUPPORT

1. Upload faq.html to your website root and replace the existing faq.html.
2. Upload api/gemini-chat.js to /api/gemini-chat.js.
3. In Vercel Environment Variables keep:
   GEMINI_API_KEY = your Gemini API key
   Environment: Production
4. Redeploy the Vercel project.

The AI Support is now embedded directly inside the FAQ page. There is no floating button and no extra click to open the chat. Visitors can type directly into the visible AI Support box.

Never place GEMINI_API_KEY inside faq.html or any browser-side JavaScript.
